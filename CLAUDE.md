# Ryan's portfolio site

## Design source of truth
- design/reference.html is the approved design. Match its layout, typography,
  colours, spacing and components exactly. Don't invent new styles.
- If something isn't covered by the reference, ask before deciding.

## Tech
- Plain static HTML/CSS/JS (no framework unless I ask). Output lives in /site.
- Mobile-first and responsive; check at phone, tablet and desktop widths.
- Videos are YouTube/Vimeo embeds, lazy-loaded. Never commit video files.

## Workflow
- Commit after each working change with a clear message.
